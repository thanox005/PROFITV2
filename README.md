⚽ Bolão Brasileirão
Aplicativo de bolão do Campeonato Brasileiro. Os participantes dão palpites nos jogos, ganham pontos e acompanham o ranking.
Como funciona
5 pontos pelo placar exato
3 pontos por acertar vitória, empate ou derrota
Desempate pelo maior número de placares exatos
O palpite fecha no horário do jogo
Tecnologias
Página: HTML, CSS e JavaScript (arquivo `index.html`), hospedada no GitHub Pages
Servidor e banco de dados: Google Apps Script + Google Planilhas
Configuração
Cole o link `/exec` da implantação do Apps Script na constante `API_URL` do arquivo `index.html`.
Ative o GitHub Pages em Settings → Pages, escolhendo a branch `main`.
